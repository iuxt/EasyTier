# EasyTier 统一管理服务

Go HTTP 服务内嵌前端静态文件，运行时只需要一个服务端二进制和 MySQL 8。客户端仍复用 Rust 网络引擎。

## 部署

```sh
cd easytier-server
cp .env.example .env
# 修改 .env 中四个独立密码/token，建议使用 openssl rand -hex 32 生成
# 本机 HTTP 调试设置 COOKIE_SECURE=false；HTTPS 部署保持 true
docker compose up -d --build
```

生产环境用 Nginx/Caddy 将 `https://vpn.example.com` 反向代理到 `127.0.0.1:8080`，保留原始 Host；Web、API 使用同一域名根路径。MySQL 不需要向外暴露端口。浏览器用 `ADMIN_PASSWORD` 登录。服务默认启用 Secure、HttpOnly、SameSite=Strict 会话 Cookie；本机 HTTP 开发必须显式设置 `COOKIE_SECURE=false`。

也可以直接构建运行：

```sh
go build -o easytier-server .
export MYSQL_DSN='easytier:数据库密码@tcp(127.0.0.1:3306)/easytier?charset=utf8mb4'
export ADMIN_PASSWORD='替换成至少24字符的独立管理员密码'
export ENROLLMENT_TOKEN='替换成至少24字符的独立设备注册token'
./easytier-server
```

先建立数据库和账号，数据库字符集使用 `utf8mb4`。程序启动时连接数据库并创建缺失表；不会自动创建数据库。账号需要建表、索引、外键及数据读写权限。设备、审批、配置和日志都保存在 MySQL；管理员会话保存在内存，服务端重启后需重新登录。

| 环境变量 | 含义 |
| --- | --- |
| `MYSQL_DSN` | 必填，Go MySQL 驱动 DSN；远程 MySQL 可在 DSN 中设置 `tls=true` |
| `ADMIN_PASSWORD` | 必填，至少 24 字符，与注册 token 不同 |
| `ENROLLMENT_TOKEN` | 必填，至少 24 字符，共用的设备注册凭据 |
| `LISTEN_ADDR` | 默认 `127.0.0.1:8080`；容器使用 `0.0.0.0:8080` |
| `COOKIE_SECURE` | 默认 `true`；仅本机 HTTP 调试使用 `false` |
| `LOG_RETENTION_DAYS` | 日志保留天数，默认 7，后台每分钟分批清理 |

## 客户端

在仓库根目录构建：

```sh
cargo build --release -p easytier --bin easytier-core
sudo ./target/release/easytier-core -h https://vpn.example.com -k 注册token
```

`-h` 现在表示管理服务地址，帮助使用 `--help`。注册成功后设备出现在 Web 列表，状态为“等待审批”。选择“设置 / 审批”，通过开关选择功能，点击“同意接入”。客户端在审批前不创建网络实例，也不读取本地网络配置；原来的 `-c` 启动方式已改为只用于 `--check-config` 离线校验。

设备 UUID 和独立随机凭据默认保存在运行用户的 `~/.easytier/managed`，Unix 上目录为 0700、身份文件为 0600。用 `--state-dir /var/lib/easytier` 可以固定路径；容器必须挂载这个目录。重启须使用同一用户及身份目录，复制身份文件会被视为同一设备；不要在多台机器间共享。每个服务端地址对应独立身份，同一身份只能启动一个进程。身份文件丢失会作为新设备重新等待审批。

## 通过开关管理设备

Web 设备详情直接提供以下设置，不需要查看或编辑配置文件：

| 设置 | 行为 |
| --- | --- |
| 设备名称 | 可选，留空使用客户端主机名 |
| 自动分配内网 IP | 默认开启；关闭后填写固定内网 IPv4，例如 `10.144.0.2/16` |
| 作为接入节点 | 默认开启，服务端自动管理所需监听地址 |
| 接入地址 | 可选，填写其他设备可达的域名或 IP，无需协议、端口；留空使用注册来源地址 |
| 启用 IPv6 连接 | 开关 IPv6 节点连接 |
| 启用设备直连 | 开关设备之间的自动直连 |
| 启用 UDP 打洞 | 开关 UDP 打洞 |
| 接入节点 | 下拉选择自动连接已批准设备、指定一台设备或不主动连接 |

同一个管理服务下的设备自动使用同一内网身份。组网密钥在首次启动时随机生成并存入 MySQL，服务重启会继续使用；Web 页面和管理员接口都不返回该密钥或底层配置。底层配置只向获批客户端下发并保存在客户端内存。

新设备的监听地址由服务端自动生成，默认使用 TCP/UDP 11010，界面无需填写。接入节点的地址、接入开关或审批状态发生变化时，服务端会同步更新其他已批准设备的连接列表。原有设备设置会转换成表单选项，管理员不能再通过接口提交任意配置文本。

Go 管理服务不自动充当 VPN 中继。至少一台获批设备需要能够被其他设备访问，并开启“作为接入节点”。经过 Nginx/Caddy 反向代理时，注册来源地址通常是代理地址，应在这台设备的“接入地址”填写其可达的域名或 IP；其他设备在下拉框选择它即可。需要在入口设备的防火墙/路由器放通相应的 11010 端口。

## 运行行为

- 每 5 秒同步一次审批、配置和运行状态，设置变化时停止旧实例并应用新版本；无变化时保持运行。
- 拒绝、撤销或重新设为待审批后，下一次同步停止网络。失联时保留最后一次授权最多 45 秒，租约到期后停止网络，恢复连接并取得新授权后重新启动。停止实例存在正常的短暂连接清理时间。
- 配置仅保存在客户端内存。客户端每次重启都必须重新联系管理服务取得审批和配置，不能通过离线缓存绕过审批。
- 终端只输出注册、等待审批、配置应用、失联停机等简短状态。运行日志以 INFO 及以上级别异步上传，Web 可查看最近 500 条。
- 日志使用最多 4096 条内存队列、每批最多 100 条；失败会重试，队列满时丢弃新日志并在恢复后记录丢弃数量，不阻塞网络。进程退出会尝试发送一个批次，长时间断网或进程崩溃可能丢失日志。客户端不写本地运行日志。
- 注册 token 仅用于登记设备；后续同步和日志使用独立设备凭据。重复注册不会重置审批，管理员密码与设备 token 分开。HTTP 只允许回环地址用于本机调试，远程地址必须 HTTPS，客户端拒绝重定向。

当前版本是单管理员、小规模部署实现：不包含多租户、角色权限、操作审计、注册 token 的 Web 轮换及海量日志搜索。审批控制本客户端何时启动网络；网络协议仍使用现有 EasyTier 网络身份。已获批设备持有共享网络密钥，如果需要防止恶意设备脱离管理客户端重新接入，应另行使用逐设备凭据和协议层吊销机制。

## 验证

```sh
go test -race ./...
# 使用专用测试数据库，会插入并清理测试设备和日志
MYSQL_TEST_DSN='root:password@tcp(127.0.0.1:3306)/easytier_test?charset=utf8mb4' go test -race -v ./...
# 实际 Go 服务 + Rust 客户端端到端验证，需先构建客户端
MYSQL_TEST_DSN='root:password@tcp(127.0.0.1:3306)/easytier_test?charset=utf8mb4' python3 tests/e2e.py
```

测试使用 `no_tun`，验证注册、审批门禁、真实监听端口、开关设置更新、自动连接列表、日志、撤销、重启和失联租约，不需要 root 或创建系统 TUN。
